# Ontology visual assets

Three illustrations for the public product page and the 30-second Remotion film.
They use [the original llm-brain banner](../banner.svg) as the visual reference:
off-white drafting paper, black hairlines, violet and blue, and editorial typography.

| File | Purpose | Native dimensions |
| --- | --- | --- |
| `ontology-atlas.webp` | Overview of evidence and reuse relationships | 1672 × 941 |
| `information-field.webp` | Fragmented information becoming connected knowledge | 1672 × 941 |
| `reuse-field.webp` | A result connected back to its context and procedure | 1672 × 941 |

Created with the built-in GPT image generator on 2026-11-06. The tool does not
expose its exact model version. These are conceptual illustrations using synthetic
content, not screenshots or measured product data. The atlas was revised to remove
invented counts and to correct `artifact → procedure` direction.

Original PNGs are retained in the local project verification archive. WebP copies
use quality 94 without resizing. Remotion consumes identical copies under
`tools/intro-video/public/ontology/`. The reproducible film source and render command
are documented in [tools/intro-video](../../tools/intro-video/README.md).

The root `ontology/` directory remains private and ignored. The files in this
public asset directory contain no personal knowledge data.
