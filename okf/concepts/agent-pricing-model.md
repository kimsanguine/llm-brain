# 에이전트 과금 모델

## 핵심 요약

에이전트 시장에서 가장 치열한 싸움은 모델 성능 벤치마크가 아닌 **과금 단위 설계**에서 벌어진다. "더 좋은 모델을 쓴다"는 차별화는 6개월을 버티기 어렵다. Seat 과금은 에이전트 시대의 가치 단위와 어긋난다. 삼성SDS 에이전트 실제 도입률 5%의 핵심 원인 중 하나가 **가격 설계 실패**다.

## 상세 내용

### 시장 신호 (raw 원문 기준)

- Microsoft 부사장 라제시 자: "AI 에이전트가 곧 유료 계정의 기회. 에이전트 50개를 운영하는 기업은 50인분 라이선스를 내야 한다"
- OpenAI, Anthropic, Google, xAI: $20대 월 정액제 → 사용량 기반 전환 검토 (무제한 요금제 수익성 붕괴)
- MS AI 비즈니스: 2026년 1분기 ARR **$370억**, 전년 대비 +123% — "에이전틱 컴퓨팅"이 공식 P&L 카테고리로 등장

### 과금 구조의 세 방향 (raw 원문 기준)

**프리미엄 종량제**: Anthropic이 Claude Code 비용 두 배 인상, flat-rate → usage-based 이동. 복잡한 추론에 Opus, 단순 실행에 저비용 모델을 쓰는 내부 라우팅 전략 반영. 모델 선택이 곧 비용 전략.

**저가 진입 레이어 신설**: OpenAI가 $20 Plus와 $200 Pro 사이 공백을 $100 Codex 전용 요금제로 채움. 사용 집중도에 따른 가격 레인 분리.

**도메인 패키지 과금**: Anthropic이 금융 AI 에이전트 10종을 단일 패키지로 출시 (피치북 분석, 실적 검토, 재무제표, 신용 메모, 규제 검토 + Excel·PowerPoint·Outlook 연동). "에이전트 SKU = 도메인 패키지"라는 새 P&L 카테고리.

### Seat 과금의 근본 문제 (raw 원문 기준)

SaaS 시대의 seat 과금 논리: 인간 1명이 도구 1개 사용 = 직관적, 예측 가능.

에이전트는 이 논리를 무너뜨린다: 에이전트 1개가 동시에 수백 작업 수행 가능. 에이전트 50개 = 50인분 라이선스 요구 → 기업이 에이전트 도입 자체를 억제 → 공급자 매출 급감.

**가치 단위와 과금 단위의 불일치**가 근본 문제. 에이전트가 만드는 가치는 "도구를 쓰는 시간"이 아니라 해결된 작업의 수, 자동화된 시간, 생성된 결과물의 품질.

### 과금 단위 설계 3단계 진화 (raw 원문 기준)

#### 1단계: Usage-based (사용량 기반)

토큰, API 호출 수, 처리된 작업 수 단위. Anthropic 종량제 전환이 이에 해당.

- 장점: 사용량에 비례하는 비용 부담
- 단점: 고객의 예측 가능성 저하 ("이번 달 요금이 얼마나 나올지 모른다")
- Gemini Flash-Lite $0.25/M 입력 토큰 — 토큰 단가 전쟁은 바닥을 향함. Usage-based 가격 경쟁만으로는 마진 없음.

#### 2단계: Outcome-based (결과 기반)

"답변이 아닌 실행 결과"를 판다. AWS Bio Discovery: 신약 후보 설계와 실험 검증 결과 단위 판매.

전제 조건: **"성공"을 정의하고 측정할 수 있어야 한다** — 기술 문제가 아닌 PM 문제. PM 역할이 기능 설계자에서 평가 설계자로 전환.

채널코퍼레이션 알프: CS 월 100만 건 처리, **80% 해결률** — 11년간 CS 데이터와 룰 가드레일이 있었기에 "건당 해결" 과금 논리가 고객에게 설득됨. 데이터 없이 outcome 과금 불가능.

#### 3단계: Domain Package SKU (도메인 패키지 과금)

도메인 전문성이 가격결정력이 된다. 도메인 특화 에이전트는 "실행 결과" 측정이 쉬워 outcome 과금도 가능. **도메인 깊이가 곧 마진**.

### A2A 커머스 — 다음 층 (raw 원문 기준)

에이전트가 다른 에이전트의 서비스를 구매·판매하는 마켓플레이스. Anthropic이 에이전트 간 거래 마켓플레이스 테스트 중. 한국에서는:
- DSRV: A2A 결제 인프라, 블록체인 기반 결제 레이어, 연 5억 달러 시장 목표
- Kite AI: 에이전트 전용 메인넷 출시

이 세계에서는 기존 "사용자 계정(seat)" 개념 자체가 사라지고 에이전트가 소비자이자 공급자가 된다.

### PM이 지금 해야 할 세 가지 질문 (raw 원문 기준)

1. **우리 에이전트가 만드는 가치는 무엇인가?** — 시간 절약, 작업 해결, 매출 증가 중 무엇. 가치 단위를 정의해야 과금 단위를 잡을 수 있다.
2. **그 가치를 지금 측정할 수 있는가?** — Outcome 과금은 성공률 측정이 전제. 측정 체계 없이는 seat 또는 usage에 머문다.
3. **고객의 예측 가능성을 어떻게 보장하는가?** — 월 상한선, 예산 캡 설계 없이는 도입 결정이 나지 않는다.

### 2026-05-16 보강: 도메인이 명확할수록 결과 기반 과금이 가능하다

도메인 번들 SKU는 pricing과 직접 연결된다. 금융 에이전트는 “신용 메모 X건 처리”, 커머스 에이전트는 “전환된 캠페인”처럼 outcome 단위를 정의할 수 있다. 반대로 범용 에이전트는 성공 정의가 흐릿해 usage-based 또는 seat-like 과금으로 밀릴 가능성이 크다.

따라서 가격 전략의 순서는 모델 선택 → 요금제 설계가 아니라, **소유할 도메인 정의 → 보장할 결과 정의 → 과금 단위 설계**다.

### 2026-05-26 보강: PoC 예산에서 운영 예산으로

Anthropic 2026년 Q2 첫 흑자와 $10.9B 매출 신호는 에이전트 비즈니스가 토큰 API 판매나 PoC 컨설팅을 넘어 **반복 운영 매출**로 이동했다는 외부 검증으로 해석된다.

에이전트 비즈니스 모델은 세 단계로 압축된다.

1. **모델 API 판매**: 토큰 단위 과금. 실험이 멈추면 매출도 끊긴다.
2. **PoC + 컨설팅**: 3-6개월 프로젝트 단위. 성공해도 다음 예산 라운드에서 재심의가 필요하다.
3. **운영 패키지**: 월별 사용량 계약, 성과 기반 구독, 도메인 패키지 SKU. 업무 플로우에 붙어 반복 갱신된다.

한국 PM에게 중요한 변화는 제안서 언어다. "AI 에이전트 파일럿"은 일회성 예산으로 읽히고, "에이전트 기반 [업무명] 운영 체계"는 월별 KPI와 반복 예산의 언어가 된다.

### 2026-06-05 보강: 인터랙티브 채팅과 자동화 에이전트 과금 분리

The Diff raw는 Anthropic이 2026-06-15부터 Claude 구독자 중 agent SDK, claude -p 스크립트, CI 파이프라인 자동화 워크로드를 별도 크레딧 풀로 분리한다고 정리한다. 인터랙티브 채팅은 flat-rate로 유지하되, 루프·계획·백그라운드 실행을 포함하는 자동화 사용은 미터링으로 이동한다.

이는 에이전트 가격의 중요한 선례다. 사람이 대화창에서 쓰는 사용량과, 에이전트가 반복 호출하며 목표를 완주하는 사용량은 원가 구조가 다르다. AI 제품은 "사용자 seat"와 "자동화 실행 크레딧"을 분리하고, agent loop의 검토 시간·재시도 비용까지 가격 모델에 넣어야 한다.

같은 raw의 Resend .md 가격 페이지 신호는 에이전트 구매자를 위한 마케팅도 가격 설계 일부가 됐음을 보여준다. 사람이 보는 pricing page와 에이전트가 정확히 읽는 machine-readable pricing page가 함께 필요해진다.

### 2026-06-06 보강: Economy of Minds — 에이전트 행동에 값을 매기다

NLP News는 "Economy of Minds"가 에이전트 행동(actions)에 가격을 매기는 접근이라고 기록한다(raw 원문 기준). 이는 위 A2A 커머스의 연장선으로, 과금 단위가 seat·token을 넘어 **에이전트가 수행한 개별 행동**으로 내려가는 흐름이다. 같은 호의 self-modifying harness(+19 SWE)와 multi-agent CUA는 에이전트가 더 많은 행동을 자율 수행할수록 행동 단위 과금의 측정 가능성이 핵심 설계 변수가 됨을 보여준다. 자기 개발을 가속하는 시스템 맥락은 [recursive-self-improvement](/concepts/recursive-self-improvement.md)를 참조한다.
