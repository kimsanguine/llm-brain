# T3-TEACH 강의 운영 패턴 및 인사이트

## 핵심 요약

T3-TEACH 클라이언트의 강의 세션 운영 패턴과 수강생 프로젝트 발표 트렌드를 MeetFlow 주간 요약에서 추출한 운영 인사이트. 2026-05-14~21 주간 요약에서 수강생 발표 6건이 반복 분석되며, 핵심 축은 현장 대응형 AI 서비스, 온디바이스/엣지, 저지연, 데모 전달력으로 수렴했다.

## 상세 내용

### 강의 세션 운영 패턴

**세션 기록 방식**
- MeetFlow가 오디오 청크 단위(5~7분 간격)로 타임스탬프 체크포인트 기록
- 전사 완료 세션: 강의 내용 구조화
- 전사 미완성 세션: 타임라인만 기록 → 수동 재분석 필요
- 테스트 세션(2026-03-31)은 시스템 세팅 목적, 강의 내용 없음

**반복 결정사항**
- Notion 동기화로 세션 메타데이터 보관
- 정기 체크포인트 회의: 약 130분 세션 (체크포인트 24개 기록)
- 도구: Zoom 온라인 + 마이크 녹음 방식

### 수강생 AI 프로젝트 발표 (2026-05-14~21, 6건)

2026년 5월 14일, 18일, 21일 주간 요약에서 반복 정리된 수강생 발표 6건의 주제와 공통 패턴. 5월 18일과 21일 요약은 동일한 발표군을 “현장 문제를 즉시 해결하는 AI 서비스” 관점으로 재압축했다. 5월 25일 주간 요약에서는 최근 3일 신규 notes가 없어 같은 발표군을 최신 수집본으로 유지했다.

**발표 주제 목록**

| 프로젝트명 | 기술 스택 | 핵심 포인트 |
|---|---|---|
| AI동화앱 마마파파텔러 | 11Labs + TTS (Qwen3) | 부모 목소리 클로닝, 40초 녹음 → 보이스 생성 파이프라인 |
| AI보이스피싱대응솔루션 | STT + 딥페이크 탐지 + NLU | 기관 사칭/금전 요구/개인정보 요구 탐지, 온디바이스 처리 |
| 다문화가정정보격차해소앱 | OCR + LLM 보정 + 번역 | 통신문/안내문 번역, 도메인 용어 보호, 알림·체크리스트 연결 |
| 수어기반양방향통역키오스크 | MediaPipe + CNN/GRU | 수어↔음성 양방향, 병원 상담용, 상담 요약 카카오톡 전송 |
| 시각장애인보행보조AI | YOLOv3-Tiny TF Lite | 온디바이스 객체 탐지, 36ms 응답, 음성+진동 피드백 |
| 음향기반위험감지시스템 | HuBERT + Whisper STT | 무단침입/응급상황 탐지, TTS 경고 + 관제 대시보드 |

**공통 기술 트렌드**
- 실시간성 / 저지연 설계 반복 등장
- 온디바이스·엣지 처리 (개인정보 외부 유출 최소화 목적)
- 멀티모달 파이프라인 (음성, 이미지, 텍스트 결합)
- 문제 정의 명확: 교육, 안전, 의료, 접근성
- 모델 성능보다 사용자 상황 인식 → 즉시 행동 연결이 발표의 핵심 평가축
- 데모 완성도는 높지만 설명과 화면 매칭이 약하면 전달력이 흔들림
- 사용자가 실제로 겪는 심리적 판단 마비, 시간 부족, 정보 격차, 상담 단절, 보행 위험, 관제 사각지대를 얼마나 빠르게 줄이는지가 제품성의 중심으로 반복 확인됨

**발표 피드백 패턴**
- 잘된 점: 문제 정의 명확, 데모 작동
- 개선 필요: 설명-화면 매칭 약함 → 전달력 저하
- 요청사항:
  - 핵심 지표와 사용자 시나리오 한 줄로 고정
  - 데모 영상에 "지금 무슨 기능인지" 자막/포인터 보강
  - 오탐/미탐, 지연, 실패 시 복구 시나리오 명확히 정리

**2026-05-18 추가 인사이트**
- AI 보이스피싱 대응은 STT·딥페이크 탐지·NLU를 묶어 기관 사칭/금전 요구/개인정보 요구를 동시에 잡는 구조가 강점.
- 수어 키오스크와 시각장애인 보행보조는 모델 정확도보다 상담 흐름과 지연시간 같은 현장 지표가 더 중요.
- 음향 기반 위험 감지는 탐지 후 관제 대시보드, TTS 경고, 이벤트 로그까지 이어지는 운영 상태 설계가 눈에 띔.

**2026-05-21 재요약 인사이트**
- 보이스피싱 대응 발표의 강점은 기술 탐지가 아니라 고객 심리와 판단 마비 문제를 제품 문제로 재정의한 점.
- 마마파파텔러는 부모 목소리 클로닝 자체보다 40초~1분 녹음 후 1분 30초 안팎 재생으로 이어지는 짧은 서비스 흐름이 제품성의 핵심.
- 다문화가정 앱은 OCR/정규식 이후 핵심 문장 추출, 카테고리 분류, 번역 보정, 슬롯 프로텍션, 글로서리 인젝션까지 이어지는 문서 파이프라인이 실전적.
- 데모 보강의 반복 처방은 “핵심 지표 1개 + 사용자 시나리오 1개 + 지금 무엇을 보는지 자막/포인터 + 오탐/미탐/지연/복구 한 줄”로 압축된다.
